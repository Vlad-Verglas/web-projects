## Repository structure

Every project has its own folder. The HTML files live in the project root, and the styles and scripts are kept in two separate folders.

```
web-projects/
├── README.md
├── project-one/
│   ├── README.md
│   ├── index.html
│   ├── css/
│   │   └── style.css
│   └── js/
│       └── script.js
├── project-two/
│   └── ...
└── ...
```

## How to run a project

No build tools are needed. Clone the repo and open the `index.html` of any project in your browser:

```bash
git clone https://github.com/<your-username>/web-projects.git
cd web-projects/<project-folder>
```

Then open `index.html` in a browser (or use a local server of your choice).

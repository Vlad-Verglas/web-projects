Boutique Project

A multi-page website for a handmade clothing boutique, written in plain HTML. Every page has its own style: rococo, V-Kei, alt, goth, nusantara, wedding, accessories and Y2K.

This is my first HTML project and a learning exercise. Everything in it is fictional: the shop name, the pieces, the descriptions and the email address are placeholders.

Why this project

My girlfriend asked me to build something for her for the first time, so this felt like a good chance to test what I have learned in the last few weeks. I also wanted something a bit different from the usual first project. I haven't seen many sites where every page has a completely different personality, and since I love many of these styles, it will also be a fun way to practice CSS later on.

I was short on time at the start, so I asked an AI assistant for a base structure, then went through it to understand how each part works. It is not perfect, and I'm learning without leaning on AI too much. I'm also a student and sometimes work, so progress will be steady rather than fast.

How it is built
Head: character encoding, viewport meta tag (so it works on phones), page title.
Header: a nav with links to every page, repeated on each page so you never have to go back to the home page.
Main: a section with the page title and a short introduction, followed by a section with one article per piece (or per style, on the home page).
Lists: the style pages also use lists, for example for the available options.
Footer: copyright and a contact email.
The body of each page has a class with the name of its style (for example class="rococo"), ready for the CSS themes.

All pages follow the same structure and only the text changes.

What I practiced

Semantic HTML (header, nav, main, section, article, footer), headings, lists, links between pages and the basic head setup.

Run it locally

Download the files into one folder and open index.html in your browser. No installation or server is needed.
